# Interactive Product Inventory & Analytics Dashboard

Hey! This is the capstone mini project from the JavaScript assignments.  
It's a simple console-based app that asks you for a product name and price, then shows you inventory analytics.  
I'll explain how to run it step by step. No fancy setup needed, just a browser.

## What You Need

- A web browser (Chrome, Firefox, Edge, Safari, whatever you have)
- The capstone code (the big JavaScript block from the assignment)
- 2 minutes of your time

## Steps to Run It

1. **Open your browser**  
   Just launch Chrome or Firefox like you normally do.

2. **Open Developer Tools**  
   - Press `F12` on your keyboard, **OR**
   - Right-click anywhere on the page and click **Inspect**.
   - A panel will open on the right or bottom.

3. **Go to the Console tab**  
   In the Developer Tools panel, click on the **Console** tab.  
   It looks like a little terminal where you can type JavaScript.

4. **Copy the capstone code**  
   Copy the entire code block from the assignment.  
   It starts with `let inventory = [...]` and ends with the discount logs.

5. **Paste it into the Console**  
   Click inside the Console, paste the code (Ctrl+V or Cmd+V), then press **Enter**.  
   The code will start running immediately.

6. **Answer the prompts**  
   - First, a prompt will ask: **"Enter new product name:"**  
     Type something like `Monitor` and click OK.
   - Next, it will ask: **"Enter new product price:"**  
     Type `150` and click OK.

7. **See the output**  
   The console will print a bunch of stuff — the inventory roster, categories, total value, filtered items, etc.  
   Scroll up in the console if you miss it.
